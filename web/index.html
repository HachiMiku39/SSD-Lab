从厂商资料中能学到什么
资料公开的方法对本工具的启发

          
三星 PM863 白皮书 ↗fio、混合负载、QD 扫描和 99.99% 延迟；多数项目先做设备写入预处理，顺序项目除外。新增 R70/W30 队列扫描与尾延迟，完整保留原始 fio 输出。公开例子不能代表三星所有产品的内部验收流程。

          
三星 990 PRO 数据表（2022）↗指定 Iometer、主机和辅助盘条件；写性能启用 Intelligent TurboWrite。报告记录测试条件；短时峰值不能直接当作缓存耗尽后的持续写入速度。

          
SK hynix eSSD 虚拟化资料 ↗强调多个工作负载下的延迟和 I/O 一致性。关注混合负载与干扰，而不是把一个纯读峰值当作整体性能。

          
SNIA SSS PTS 2.0.2（2020）↗定义预处理、测量窗口、稳态判据、负载矩阵和报告要求。正式设备级稳态需要完整前置流程；几轮短文件测试不足以判断设备达到稳态。

          
OCP Datacenter NVMe SSD 2.7 ↗设备延迟监测和异常诊断；区分设备命令延迟与主机影响。本工具显示 fio 主机侧总延迟，不把它冒充控制器内部延迟。

        

        
推荐先读的论文

          
Practical Erase Suspension for Modern Low-latency SSDs ↗
USENIX ATC 2019 · 含三星作者
研究擦除对尾延迟的影响，观察 4 KiB、70% 读 / 30% 写的混合负载。部分机制通过经实机校验的模拟器评估，不是厂内量产测试规范。

          
A New LSM-style Garbage Collection Scheme for ZNS SSDs ↗
HotStorage 2020 · 含 SK hynix 作者
使用真实 ZNS 研究原型，考察利用率、更新分布和垃圾回收开销。其 ZNS 管理方法不能直接套用到普通消费级 SSD。

          
Design Tradeoffs for SSD Performance ↗
USENIX ATC 2008 · 基础架构研究
理解内部并行、工作负载和清理行为为何共同决定性能。适合建立分析框架，不用于推断现代产品的具体速度。

          
Reducing Solid-State Drive Read Latency by Optimizing Read-Retry ↗
ASPLOS 2021 · NAND 读重试研究
从真实 NAND 芯片研究读重试。说明老化和保持时间可能影响读取延迟；普通 SMART 无法直接观察所有芯片内部机制。

已支持
纯读写、70/30 混合、QD1/4/16/32、真实尾延迟、逐轮结果、带宽中位数 / CV、原始命令、系统与容量条件。
尚未验证

持续写入曲线
后续使用足够大的工作范围与累计写入量，再结合温度和空闲恢复观察；不能仅凭一条速度下降曲线断言 SLC 缓存耗尽。
实验室稳态
独立空盘、专用测试平台与明确的清除 / 全盘预处理流程；需要和日常目录测试分开设计。
